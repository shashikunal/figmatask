Figma Settings & Extraction Guide

How to get Colors, Fonts, Images, Videos from Figma — for interview demo

File: TEKNIC EUCHNER - INTERVIEW.fig (1440×7592, 577 nodes) | 44 images + 1 video

⚠ If Figma asks “Upgrade to Dev Mode”: Skip Dev Mode — stay in Design Mode. Select layer → Right panel Fill gives HEX, Typography gives font — copy there. No payment needed. Assets already in assets/ (44 PNG + hero.mp4) from .fig.zip.

0. Open File & Basic Figma Settings

Open

  1. Open Figma Desktop App (better than browser for export) → Open → TEKNIC EUCHNER - INTERVIEW.fig or drag .fig onto Figma window.
  2. If you have link https://www.figma.com/design/VmU4CMyskr5EBI0lzhSgs9/... → Click Duplicate to drafts to get editable copy.

Settings to Enable (Top Menu)

  • View → Rulers (Shift+R) → shows X,Y coordinates — needed to get x=80, y=480 for hero.
  • View → Outline Stroke → see actual bounds.
  • View → Pixel Grid → ensures 1px lines are sharp.
  • File → Show in Figma → Preferences → Nudge amount 1px → for measuring gaps.

Enable Dev Mode (for code)

  1. Top bar toggle: Design ↔ Dev Mode (or press Shift+D)
  2. Dev Mode shows Inspect panel on right: CSS, iOS, Android code for selected layer.
  3. Set Code language to CSS (click CSS tab) → copy exact background: #E60000; font-size: 50.81px
Interview tip: Say “I switch to Dev Mode, select layer, copy CSS — that gives pixel-perfect colors/fonts/sizes.”

1. Extract Colors (3 ways)

Method A — Select any Frame/Text → Right Panel → Fill

  1. Select header Frame 4 (1:621) → Right panel → Fill → see solid color → Click color swatch → Copy #151B20 (header) or #E60000 (button).
  2. Select hero title 1:157 → Fill → #FFFFFF white.
  3. Select muted text 1:179 → Fill → #5C5C5C gray.

Method B — Dev Mode Inspect

  1. Dev Mode → Click layer → Right Inspect → Colors → shows HEX + opacity → Click copy icon.
  2. Shows all fills on page: #E60000, #0F0F0F, #151B20, #F6F6F6 etc.

Method C — Styles Panel (if styles created)

  1. Left sidebar → Assets → Colors → Lists style names like Primary #E60000, Secondary #0F0F0F → Right-click Copy.

How we did via code (automated):

for (n of nodeChanges) {
  for (p of n.fillPaints || [])
    if (p.type==='SOLID' && p.visible)
      hex = `#${
        [p.color.r,p.color.g,p.color.b]
        .map(v=>Math.round(v*255).toString(16).padStart(2,'0')).join('')
      }`.toUpperCase()
  // p.color.r 0.1176 → 30 → 1E → #1E1E1E
}

3. Extract Images (Export)

Method A — Select Image Layer → Export (Best)

  1. Select product image image 6afd91... at 1:689 (Inductive switch) → Right panel bottom → Export → + → PNG 1x, 2x → Export ... → Saves image.png.
  2. For multiple: File → Export → Export all images → Figma exports 44 images to zip.
  3. Slice Tool (S): Draw slice over area → Export slice as PNG.

Method B — Right-click Copy

  1. Right-click image → Copy/Paste as → Copy as PNG → Paste in browser to download.
  2. Or Plugins → Image Export.

Method C — From .fig.zip (we did)

  1. Unzip TEKNIC EUCHNER - INTERVIEW.fig.zip → images/ folder has 44 files named by hash 6afd91a24685d3ba... (no extension).
  2. Rename 6afd91a2 → 6afd91a2.png → copy to assets/images/.
  3. Map hash to Figma: In decoded JSON fillPaints[IMAGE].image.hash bytes → hex → filename.

4. Extract Videos

Figma Video is special — not exportable via right panel

  1. In Figma, video appears as Rectangle with Fill → Video or Prototype → Video. Select hero bg 1:154 Inside Teknic... → Right panel → Fill shows Video thumbnail → No Export button.
  2. Workaround 1: Right-click layer → Copy link → Open in browser → Download.
  3. Workaround 2 (we did): From .fig.zip → videos/851ad0bf1f180ea4b... (28 MB) → Copy to assets/hero.mp4 → Use in HTML: 
    <video autoplay muted loop playsinline poster="ff21ce...png">
  <source src="assets/hero.mp4" type="video/mp4">
</video>
  4. Workaround 3: Plugins → Video Export or ask designer for original MP4.
Interview: “Videos in Figma are embedded; I get them from .fig.zip videos folder or request source MP4 from designer — then use <video> with autoplay muted loop playsinline.”

Code automated:

imageNodes = changes.filter(c=>c.fillPaints?.some(p=>p.type==='IMAGE'))

5. Extract Spacing / Sizes (for pixel perfect)

  1. Select Frame 1:153 Hero 1440x810 at (0,0) → Top shows W 1440 H 810 X 0 Y 0 — copy to CSS width:1440px; height:810px or height:810px; position:absolute top:-31px left:-55px size 1550x872 for video.
  2. Select Frame 8 at (80,480) 587x264 → X 80 Y 480 → CSS left:80px; top:480px; width:587px → In code we center via left:50%; transform:translateX(-50%) with 587+296+397=1280.
  3. Use Alt + Hover between layers to see red gap (e.g., 30px between title and subtitle, 20px between buttons).
  4. Dev Mode → Inspect → Layout → Shows gap, padding, grid.
.hero__content{position:absolute; top:480px; left:50%; transform:translateX(-50%); width:1280px}
.hero__left{width:587px} /* Frame 8 */
.hero__right{width:296px} /* Frame 5 at 1064 → 80+587+397+296=1440 */
