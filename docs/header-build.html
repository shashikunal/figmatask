Explain Each Line

Why this HTML?
header → semantic
header__inner → flex
img width/height → no layout shift
nav aria-label → a11y
href="#home" → smooth scroll
Teacher says: “header tag, not div — interview asks why semantic. nav aria-label Primary — screen reader. img width 210 height 22 prevents shift.”

2 Step 2 — Link CSS (30 sec) — Watch 0:45-1:15

VS Code — index.html head

<head>
  <link rel="stylesheet" href="css/desktop.css">
  <link rel="stylesheet" href="css/mobile.css">
</head>
<header class="header" id="header">
  <!-- class → CSS .header -->
  <!-- id → JS getElementById -->

Why class vs id?

class="header" → CSS .header (reusable)
id="header" → JS getElementById (unique)
Connect: HTML class → CSS dot
Teacher: “Class for style, id for JS — basic but interview will ask. Write link, save, we’ll write CSS next.”

3 Step 3 — Write CSS Desktop (2 min) — Watch 1:15-2:30

VS Code — css/desktop.css

.header{
  position:fixed; /* stays on scroll */
  top:30px; /* Figma Y 30 */
  left:50%; transform:translateX(-50%);
  /* X 80 = (1440-1280)/2 → centered */
  width:1280px; /* Figma W 1280 */
  height:60px; /* Figma H 60 */
  background:#151B20; /* Figma Fill */
  border-radius:6px;
}

Preview — Browser

Save → Refresh http://localhost:8199
Header at top 30, centered 80 gutters
Dark #151B20, 60px tall
Matches Figma exactly at 80,30
Teacher: “Why transform not margin-left:-640? Transform works on file:// when window <1280, margin fails → left shift bug we fixed. Why max-width calc(100% -32px)? Keeps 16px gutters on phone.”

5 Step 5 — JS (If Required, 30 sec) — Watch 3:15-3:45

// Burger — basic
const burger = querySelector('.header__burger');
burger.addEventListener('click',()=>{
  nav.classList.toggle('is-open');
});
// Hide on scroll
window.addEventListener('scroll',()=>{
  header.style.transform=
   'translateX(-50%) translateY(-88px)';
});

When JS needed?

Desktop: No JS needed
Mobile: Burger toggle → JS
Scroll: Hide header → JS
All basic: querySelector, addEventListener
