Teacher: “Why header tag? Semantic — SEO knows it’s navigation. Why aria-label? Screen reader says ‘Primary navigation’. Why width/height on img? Prevents layout shift before image loads. Why href #home? Enables smooth scroll to section. Copy exactly — interview will ask ‘why semantic?’”

3 CSS — Style #header Exactly (Basic, No Advanced)

In css/desktop.css — basic flex, fixed, transform. Each line matches Figma.

Desktop CSS (1440) — Copy line by line

/* HEADER 1:621 — 1280x60 at y=30 — FIX: was margin-left:-640 now transform */
.header{
  position:fixed;      /* stays visible when you scroll */
  top:30px;            /* Figma Y 30 */
  left:50%;            /* center trick */
  transform:translateX(-50%); /* moves left half width → centered → X 80 on 1440 */
  width:1280px;        /* Figma W 1280 */
  max-width:calc(100% - 32px); /* keeps 16px gutters when window <1280, prevents left shift */
  height:60px;         /* Figma H 60 */
  background:#151B20;  /* Figma Fill #151B20 you copied */
  border-radius:6px;   /* Figma Radius 6 */
  z-index:100;         /* stays above hero video */
}

  display:flex;                /* basic flex row */

  align-items:center;

4 JS — Interaction for #header (If Required, Basic)

Header needs 2 JS features — both basic for interview.

1. Burger Toggle (Mobile) — Basic DOM + Events

// Select elements (basic querySelector)
const burger = document.querySelector('.header__burger');
const nav = document.querySelector('.header__nav');

// Click event (basic addEventListener)
burger.addEventListener('click', () => {
  const isOpen = nav.classList.toggle('is-open'); // toggle class
  nav.style.display = isOpen ? 'flex' : ''; // show/hide nav
  nav.style.position = isOpen ? 'absolute' : '';
  nav.style.top = isOpen ? '70px' : '';
  nav.style.background = isOpen ? '#151B20' : '';
});

Interview Q: “What is classList.toggle?” — A: Adds class if missing, removes if present. Basic.

2. Hide on Scroll + Smooth Scroll (Basic)

// Hide header when scrolling down past 400px
let lastY = 0;
window.addEventListener('scroll', () => {
  const y = window.scrollY; // current scroll
  if (y > 400 && y > lastY) {
    header.style.transform = 'translateX(-50%) translateY(-88px)'; // hide up
  } else {
    header.style.transform = 'translateX(-50%) translateY(0)'; // show
  }
  lastY = y;
}, {passive:true});

// Smooth scroll with offset for fixed header (72px)
document.querySelectorAll('a[href^="#"]').forEach(a => {
  a.addEventListener('click', e => {
    e.preventDefault(); // stop jump
    const target = document.querySelector(a.getAttribute('href'));
    const top = target.getBoundingClientRect().top + scrollY - 72;
    window.scrollTo({top, behavior:'smooth'});
  });
});

Why -72? Header height 60 + 12 gap — so title not hidden under fixed header. Basic scrollTo API.

Teacher: “No JS needed for desktop header — only mobile burger and scroll. All use basic: querySelector, addEventListener, classList, style, scrollTo. Easy to explain.”
